# BIKUBOO Profile + Trust + Ratings

## 1. Run the new SQL
Open Supabase → SQL Editor, paste **PROFILE_RATINGS_SETUP.sql**, and Run.

This adds profile details, verification-request status, avatar storage, and ride ratings/reviews. Users can request verification, but only your future admin process should mark a profile as verified.

## 2. Use the app
Extract the ZIP and double-click `index.html` in Chrome.

Log in → scroll to **Profile** → add your details and optional profile photo → Save profile.

Accepted rides that have already passed their scheduled time show a **Rate driver** button. Drivers can rate accepted passengers from **My rides → Rides I offer**.
